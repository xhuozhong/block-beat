# 方块节拍 / Block Beat

用 [Codex Game Studio Plus 4.0](https://github.com/xhuozhong/codex-game-studio-plus) 的工作流制作的俄罗斯方块小游戏。单人、原创界面、无需下载素材，不是官方 Tetris 产品。

原生 HTML / CSS / Canvas / JavaScript，无构建步骤、无运行时依赖。支持桌面键盘与手机触屏，包含落点预览、暂存、七袋随机与程序合成音效。

## 直接游玩

**[点击在线试玩 → 方块节拍](https://xhuozhong.github.io/block-beat/)**

GitHub Pages 托管，可直接在浏览器游玩，无需安装。电脑用键盘，手机用屏幕按钮。

在仓库选择 **Code → Download ZIP**，解压后打开 `index.html`。代码按现代浏览器离线运行设计，无需 Python、Node、账号或联网。所有脚本与素材都在本目录；不要只复制 HTML 文件。自动化验收使用 Chromium 的 HTTP 预览；直接文件启动及其他浏览器仍需手动检查。

若需要本地网页地址，在本目录运行 `python -m http.server 8766 --bind 127.0.0.1`，打开 `http://127.0.0.1:8766`。服务器仅用于本地预览，不是公网部署。

## 操作

| 输入 | 动作 |
| --- | --- |
| ← / → | 移动，支持长按 |
| ↑ / X | 顺时针旋转 |
| Z | 逆时针旋转 |
| ↓ | 软降，每格加 1 分 |
| 空格 | 硬降，每格加 2 分 |
| C / Shift | 暂存或交换，每块一次 |
| P / Esc | 暂停/继续 |

窄屏提供触屏按钮。切走页面自动暂停，返回后手动继续。帮助界面不会让游戏在后台继续。

## 规则与特点

- 10×20 棋盘、七袋随机、三块预览、落点预览、一次暂存/每块。
- 1/2/3/4 行分别获得 100/300/500/800 × 消行前等级的分数。
- 每消 10 行升级；下落速度逐步加快。450ms 落地延迟，每块最多 15 次移动/旋转重置。
- 简化踢墙，无 T-spin、背靠背、连击额外分数；不声称完整 SRS 或官方规则兼容。
- 程序合成动作音效，无外部音乐或音频采样。首次交互解锁音频，可静音。
- 最高分和静音偏好保存在本机；无联网存档或追踪。文件模式/隐私设置可能阻止存储，游戏仍可游玩。本局进度不保存。
- 尊重系统减少动态效果设置。画布有操作说明与状态播报，但没有实现完整非视觉棋盘操作模式。

## 源码与检查

- `engine.js`：与浏览器无关的规则、带种子的七袋、事件与计分。
- `game.js`：Canvas 绘制、交互、音效、存储、诊断展示。
- `style.css` / `index.html`：响应式界面与帮助。
- `tests/engine.test.cjs`：运行 `node --test tests/engine.test.cjs`。
- `progress.md`：功能契约、专家分工与实际验收记录。

在本地地址后加 `?qa=1` 可显示明确标注的开发验证工具：单行、四行、升级、结束预置棋盘与状态文本。预置场景不写最高分；它们只是测试辅助，不能作为普通玩家自然完成的成绩。正式入口不显示测试工具。
